Search by alphabetic code (`CLP`), numeric code (`152`), name in English or Spanish, or country. The table lists every code; the output box holds the matches as text to copy.

The data is a static snapshot embedded in the site: it includes the latest codes (`ZWG`, `XCG`, `SLE`, `VED`) and Bulgaria in the euro. `N/A` means ISO defines no minor unit (metals, funds and special units). Country names come from your browser.
