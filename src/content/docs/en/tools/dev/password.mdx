Passwords are generated in your browser with `crypto.getRandomValues` and unbiased sampling. They are never put in the URL, the history or snippets; only the options are shareable.

<ToolEmbed slug="password" />

## Options

- **Password**: length (4 to 256) and character sets `a-z`, `A-Z`, `0-9` and symbols. Every chosen set appears at least once. **Exclude ambiguous** drops `I l 1 O 0 o` and quote-like characters.
- **Passphrase**: 2 to 20 words from a built-in list of 256 short English words (8 bits each), a separator, capitalized words and an optional digit.
- **How many**: 1 to 50 at once. **Generate again** draws a new batch.

## Entropy and strength

Entropy is `length × log2(pool size)` for passwords and `words × 8` bits (plus about 3.3 for the digit) for passphrases. The label is weak below 40 bits, fair below 60, strong below 90 and very strong from 90 up. For accounts, 60 bits or more is a good minimum; use a password manager to store them.

| Settings                   | Entropy   |
| -------------------------- | --------- |
| 20 characters, all sets    | ~130 bits |
| 12 characters, `a-z` `0-9` | ~62 bits  |
| 6-word passphrase          | 48 bits   |
