## Notes

- Errors show the line and column: mismatched tags, bad attributes, unescaped `&` and more.
- The message type comes from the `xmlns` namespace, or from the first known element if there is none.
- Text and CDATA are kept as they are. Minify removes comments and whitespace between elements.
- This checks that the XML is well formed. It does not validate against the ISO 20022 XSD schemas.
