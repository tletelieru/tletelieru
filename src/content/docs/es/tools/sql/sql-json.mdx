Elige un dialecto, una columna JSON y una ruta de clave, y luego pega los valores que quieres buscar.

<ToolEmbed slug="sql-json" />

## Opciones

- **Dialecto**: Postgres (`jsonb`) o MySQL (`JSON`).
- **Operación (Postgres)**: cadena de flechas `->>`, ruta `#>>` o contención `@>`.
- **Operación (MySQL)**: `JSON_UNQUOTE(JSON_EXTRACT(...))`, flecha `->>` o `JSON_CONTAINS`.
- **Columna**: la columna JSON, `meta_data` por defecto.
- **Ruta de la clave**: notación con puntos, `reference` o `nested.key`. Cada clave admite letras, dígitos, `_` y `-`.
- **Tamaño de lote**: divide listas `IN` largas en varias cláusulas unidas con `OR`.
- **Separar por**, **Quitar duplicados**, **Quitar comillas existentes**, **Diseño** y **Palabras clave en mayúsculas** se comparten con las demás herramientas SQL.

Un solo valor usa `=` y varios usan `IN (...)`. La contención arma una condición por valor unida con `OR`. Los valores se escapan para literales de texto SQL y, dentro de los documentos de contención, también para JSON; en MySQL además se duplican las barras invertidas.

## Ejemplos

| Dialecto | Operación | Ruta         | Resultado                                                            |
| -------- | --------- | ------------ | -------------------------------------------------------------------- |
| Postgres | `->>`     | `reference`  | `meta_data->>'reference' IN ('a', 'b')`                              |
| Postgres | `->>`     | `nested.key` | `meta_data->'nested'->>'key' = 'x'`                                  |
| Postgres | `#>>`     | `nested.key` | `meta_data #>> '{nested,key}' = 'x'`                                 |
| Postgres | `@>`      | `reference`  | `meta_data @> '{"reference": "a"}'`                                  |
| MySQL    | extract   | `reference`  | `JSON_UNQUOTE(JSON_EXTRACT(meta_data, '$.reference')) IN ('a', 'b')` |
| MySQL    | `->>`     | `reference`  | `meta_data->>'$.reference' = 'a'`                                    |
| MySQL    | contains  | `reference`  | `JSON_CONTAINS(meta_data, '"a"', '$.reference')`                     |
