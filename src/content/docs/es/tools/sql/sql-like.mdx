Escribe una columna y pega los valores para obtener `col LIKE '%a%' OR col LIKE '%b%'`.

<ToolEmbed slug="sql-like" />

## Opciones

- **Coincidencia**: contiene `%v%`, empieza con `v%`, termina con `%v` o exacta.
- **Conector**: `OR` o `AND` entre condiciones.
- **NOT LIKE**: niega cada condición.
- **ILIKE (Postgres)**: coincidencia sin distinguir mayúsculas.
- **Escapar % y \_**: trata los comodines de los valores de forma literal anteponiendo `!` a `%`, `_` y `!`, y agrega `ESCAPE '!'` a las condiciones que lo necesitan. Funciona en Postgres, MySQL, SQLite, SQL Server y Oracle.
- **Envolver en paréntesis**: envuelve la cadena cuando hay más de una condición.
- **Tamaño de lote**: divide la cadena en grupos separados por una línea en blanco.
- **Separar por**, **Quitar duplicados**, **Quitar comillas existentes**, **Escapar comillas**, **Diseño** y **Palabras clave en mayúsculas** se comparten con las demás herramientas SQL.

## Ejemplos

| Entrada     | Opciones            | Resultado                              |
| ----------- | ------------------- | -------------------------------------- |
| `a, b`      | columna `name`      | `(name LIKE '%a%' OR name LIKE '%b%')` |
| `gmail.com` | termina, NOT, ILIKE | `email NOT ILIKE '%gmail.com'`         |
| `O'Brien`   | exacta              | `last_name LIKE 'O''Brien'`            |
| `txn_1`     | escapar comodines   | `id LIKE '%txn!_1%' ESCAPE '!'`        |

## MongoDB

Cambia **Destino** a MongoDB para obtener filtros `$regex`. Los valores se escapan para regex y el modo de coincidencia agrega anclas: contiene no lleva, empieza usa `^`, termina usa `$` y exacta usa ambas. **OR** / **AND** pasan a `$or` / `$and`, **NOT** envuelve cada regex en `$not` y la opción sin distinguir mayúsculas agrega `"$options": "i"`. Un solo valor entrega la condición sola.

| Valores                  | Resultado                                                    |
| ------------------------ | ------------------------------------------------------------ |
| `gmail.com` (termina, i) | `{ "email": { "$regex": "gmail\\.com$", "$options": "i" } }` |
| `a`, `b`                 | `{ "$or": [{ "email": { "$regex": "a" } }, ...] }`           |
