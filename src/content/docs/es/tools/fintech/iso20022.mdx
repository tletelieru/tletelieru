## Notas

- Los errores muestran línea y columna: etiquetas que no cierran, atributos mal formados, `&` sin escapar y más.
- El tipo de mensaje sale del espacio de nombres `xmlns`, o del primer elemento conocido si no hay uno.
- El texto y los CDATA se mantienen tal cual. Minificar quita comentarios y espacios entre elementos.
- Esto revisa que el XML esté bien formado. No lo valida contra los esquemas XSD de ISO 20022.
