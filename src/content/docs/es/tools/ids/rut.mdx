Pega un RUT por línea. Se aceptan puntos, guiones, espacios y la `k` en minúscula.

<ToolEmbed slug="rut" />

## Modos

- **Validar**: revisa el dígito verificador (módulo 11) e indica el esperado cuando no coincide.
- **Formatear**: normaliza cada línea al formato de salida elegido.
- **Generar**: crea RUTs válidos aleatorios para datos de prueba.

## Formato de salida

- **Puntos y guion**: `12.345.678-5`
- **Solo guion**: `12345678-5`
- **Sin separadores**: `123456785`
- **K mayúscula**: alterna `10.000.013-K` ↔ `10.000.013-k`.

Usa **Pegar** para pasar el portapapeles directo a la entrada.

## Ejemplos

| Entrada      | Resultado                                    |
| ------------ | -------------------------------------------- |
| `123456785`  | `12.345.678-5` ✔                             |
| `12345678-9` | dígito verificador incorrecto (esperado `5`) |
| `10000013k`  | `10.000.013-K` ✔                             |
