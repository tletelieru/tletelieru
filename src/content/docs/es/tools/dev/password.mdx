Las contraseñas se generan en tu navegador con `crypto.getRandomValues` y un muestreo sin sesgo. Nunca van a la URL, el historial ni los snippets; solo las opciones se pueden compartir.

## Opciones

- **Contraseña**: largo (de 4 a 256) y tipos de carácter `a-z`, `A-Z`, `0-9` y símbolos. Cada tipo elegido aparece al menos una vez. **Excluir ambiguos** quita `I l 1 O 0 o` y caracteres parecidos a comillas.
- **Frase de contraseña**: de 2 a 20 palabras de una lista interna de 256 palabras cortas en inglés (8 bits cada una), un separador, mayúscula inicial y un dígito opcional.
- **Cantidad**: de 1 a 50 a la vez. **Generar de nuevo** crea un lote nuevo.

## Entropía y fortaleza

La entropía es `largo × log2(tamaño del conjunto)` para contraseñas y `palabras × 8` bits (más unos 3,3 por el dígito) para frases. El nivel es débil bajo 40 bits, aceptable bajo 60, fuerte bajo 90 y muy fuerte desde 90. Para cuentas, 60 bits o más es un buen mínimo; usa un gestor de contraseñas para guardarlas.

| Configuración                  | Entropía  |
| ------------------------------ | --------- |
| 20 caracteres, todos los tipos | ~130 bits |
| 12 caracteres, `a-z` `0-9`     | ~62 bits  |
| Frase de 6 palabras            | 48 bits   |
